# 로그아웃 기능 추가

**날짜:** 2026-04-29
**프로젝트:** GuidebookApp
**소요시간:** 약 30분

## 배경

앱에 로그인 기능은 있었으나 로그아웃 수단이 없어, 다른 계정으로 전환하거나 세션을 종료할 방법이 없었음.

## 상세 내용

- `Page1Activity` 상단 바에 로그아웃 버튼 추가 (교사/학생 공통 노출)
- 버튼 클릭 시: Firebase Auth `signOut()` → `LoginActivity`로 이동 (백스택 완전 초기화)
- `Page1ViewModel.logout()` → `GuidebookRepository.logout()` 계층 위임 구조

변경 파일 3개: `Page1Activity.kt`, `Page1ViewModel.kt`, `activity_page1.xml` (총 +20줄)

## 결과 및 성과

- 다중 계정 전환 가능 (교사 ↔ 학생 테스트 시 재설치 불필요)
- 세션 보안 개선: 명시적 로그아웃으로 Firebase 인증 토큰 무효화

## 기술적 의사결정

`FLAG_ACTIVITY_NEW_TASK or FLAG_ACTIVITY_CLEAR_TASK` 플래그로 백스택 전체 초기화 → 로그아웃 후 뒤로가기로 인증된 화면 접근 불가.

## 회고

단순한 기능이지만 보안 관점에서 필수. 초기 구현 때부터 포함했어야 함.
