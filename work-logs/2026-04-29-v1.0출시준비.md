# v1.0 출시 준비 — 빌드 수정, 테스트 추가, 보안 강화

**날짜:** 2026-04-29
**프로젝트:** GuidebookApp
**소요시간:** 약 4시간

## 배경

첫 번째 릴리스 버전(v1.0) 출시를 위해 빌드 안정화, 테스트 커버리지 확보, 보안 취약점 제거가 필요했음.

## 상세 내용

**빌드 수정**
- gradlew 래퍼 복원 (누락으로 인한 빌드 불가 상태 해소)
- 런처 아이콘 리소스 추가로 빌드 오류 수정
- lint 오류 2건 수정: `removeLast` API 호환성(minSdk 26), `NullSafeMutableLiveData`

**테스트 추가**
- 단위 테스트 28개: AppUser, Problem, UserNote 모델 3종 + Page1/2/3 ViewModel 3종
- 계측 테스트 3종: DrawingView, LoginActivity, Page1 역할 분기(교사/학생)
- ViewModel에 Repository 생성자 주입 리팩터링 (테스트 가능한 구조로 변경)

**보안 강화**
- Cloudinary 자격증명(API key/secret)을 소스코드에서 `local.properties`로 분리
- `.gitignore`에 `local.properties` 추가 → 자격증명 원격 저장소 노출 방지
- 릴리스 APK 서명 설정 추가

## 결과 및 성과

- 단위 테스트 28개 + 계측 테스트 3개 = 총 31개 테스트 추가
- Cloudinary 자격증명 하드코딩 제거로 보안 취약점 해소
- 릴리스 빌드 가능 상태로 전환

## 기술적 의사결정

- ViewModel에 Repository 인터페이스 대신 직접 생성자 주입: 이 규모의 앱에서 인터페이스 추상화는 과도한 설계라 판단, 생성자 주입만으로 테스트 목(Mock) 주입 가능하게 함.
- Firebase Storage 대신 Cloudinary 유지: 이미지 변환·최적화 기능 활용 목적.

## 회고

보안 이슈(자격증명 하드코딩)는 초기에 잡았어야 했음. 프로젝트 시작 시 `local.properties` 패턴을 기본으로 적용해야 함.
